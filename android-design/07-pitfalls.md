# 07 · 前车之鉴（iOS 版踩坑实录，Android 必读）

按代价排序。每条都在 iOS 上真实发生过。

## 1. 会话 cookie `_t` 会轮换 —— 绝不固定 Cookie 头
帐密登录后把 Cookie 拍快照钉成固定请求头 → Discourse 定期轮换 `_t`（Set-Cookie 下发新值，旧值仅短暂宽限）→ 若干分钟后**全线** `not_logged_in` 403、`session/current` 404。
**规矩**：cookie 全权交给 OkHttp 持久化 CookieJar 自动收发；恢复时注入、退后台时落盘。手写 `Cookie` 头会压制自动管理——禁止。

## 2. 渲染不受信 HTML：解析器必须带嵌套深度熔断
块/行内解析是互递归，每层标签一帧栈；病态嵌套（几百层）会打爆工作线程栈（iOS 协作线程栈仅 512KB）。**深度上限 40，超限把子树降级为纯文本**（顺扫到配对闭合，只留文字）。40 层远超真实内容（实测正常帖 ≤6–15 层），这是熔断线不是功能参数。

## 3. 阅读器长内容列必须懒加载
iOS 用急切 VStack 承载阅读器整页内容，在**特定设备 OS 版本**上触发 SwiftUI 布局对齐查询的指数级重测量——整机级卡死，且模拟器全绿（宽度/字号/内容逐项排除后仍只在真机复现）。改 LazyVStack 后根治。
Android 天然用 LazyColumn，但同样的教训成立：**长内容 = 懒加载容器；不要在 Column 里塞整棵帖子树**；嵌套测量密集的自定义 Layout 要警惕组合放大。

## 4. `flair_url` 有两种取值
群组资质 `flair_url` 既可能是图片路径/URL，也可能是 **Font Awesome 图标名**（如 `"gem"`）。把图标名当 URL 拉取 = 每次渲染发一条 `-1002 unsupported URL` 垃圾请求。**只有 `/` 或 `http` 开头才当图片**；图标名走 FA→本地图标映射（映射表见 iOS `UserFlair.symbol(for:)`）。同理：任何"裸字符串兜底转 URL"的分支都要求有 scheme。

## 5. Rails 枚举序列化为字符串，不是整数
`user_option.default_calendar`、`send_shortcut` 等字段是 **字符串**（Rails enum 名）。按 Int 建模会让整个 `current_user` 解码失败 → 登录流程神秘报"登录未完成"。**所有 user_option 字段先 curl 真实响应确认类型再建模**。

## 6. 一个字段类型错 = 整页数据消失（宽容解码原则）
iOS 在 `site.json` 的 trust_levels 上用错类型 + `try?` 整体解码 → 每个帖子的节点信息静默变空。规矩：外层解码失败要**可观测**（debug 断言/日志），列表项用逐项容错（一项坏不拖垮整页）；kotlinx.serialization 开 `ignoreUnknownKeys`、可疑字段用 JsonElement 过渡。

## 7. 错误呈现两条铁律
- **用户主动操作永不静默失败**：点赞/书签/回复失败必须 Toast（友好文案，见 04 映射表——不暴露状态码）；乐观更新失败要回滚。
- **首屏加载失败不能白屏也不能演示数据**：wifi 空态+重试。演示数据回填曾让用户以为在看真内容。

## 8. Cloudflare 反代的判读
`server: cloudflare` 出现在**所有**响应上，不代表被拦截。真拦截 = `cf-mitigated` 头或 403+HTML body；Discourse 自己的 403 是 JSON `{"error_type":"not_logged_in"}`。错误分类要看 body/特征头，别看 server 头。429 与 403 分开映射，别混为"权限问题"。

## 9. 聊天实时：信号化，别解析事件
MessageBus 事件 payload 各频道结构不一。**把事件当"该频道变了"的信号，重拉最新页**——复用既有映射、永远一致，代价是一次小请求。位置从 `-1` 起订，`/__status` 校准，错误退避 4s。

## 10. 上传的隐性契约
- 视频封面靠**文件名**关联：必须命名 `{videoSHA1}.png`，无 markdown 引用。
- `upload_type` 替代已废弃的 `type` 参数。
- 投票 `options[]`、偏好 `watched_category_ids[]` 等需要**有序可重复键**的 form 编码——普通 Map 表达不了。
- 红包/抽奖是**发帖成功后的第二请求**（插件无 markup，web 端靠 afterCreate 钩子）。

## 11. 交互细节的经验值
- 连续弹 sheet 会丢：收起一个再弹下一个之间隔 ~400ms。
- 下拉刷新自定义时**越阈值即触发**（Telegram 式）+ 轻触感 + 最短展示 0.6s 防闪。
- 骨架脉冲挂容器级（同相位），行级挂会错拍。
- 长无断点 token（URL）每 18 字插零宽空格，否则撑宽整页。
- 图片按已知宽高先占位（防加载后回流）；信息流媒体高按 9:16…5:4 钳制。
- 全屏看图的下拉退出要与放大平移互斥（放大态禁用 dismiss）。
- 登录页 2FA：首次提交不带码 → 服务器 `invalid_second_factor` → 就地展开验证码框，别当普通错误弹走用户。

## 12. 推送轮询的水位线
首次轮询**只建基线不弹**（否则把历史未读全轰出来）；每次把水位推进到本次响应最大 id（包括被分类过滤掉的），防止稍后改设置时旧通知补弹。
