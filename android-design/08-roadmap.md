# 08 · 分阶段交付计划

原则：每阶段可安装可试用；先只读后读写；风险最高的 HTML 渲染器最早动工。

## M0 · 地基（1–2 周）
- 工程骨架、模块划分、CI；Nocturne 主题令牌 + 组件库首批（Avatar/HeaderIconButton/Skeleton/EmptyState/Toast/NodelocLoader 三变体）。
- DiscourseClient：错误映射、cookie jar、DTO 首批（latest/site/categories）——**先 curl 定型再建模**（07-5/6）。
- 启动屏（品牌色+字标）。
**验收**：设计系统画廊页展示全部令牌/组件/加载器动画；latest 拉通。

## M1 · 只读核心（2–3 周）
- 首页三模式 + 骨架 + 分页 + 下拉刷新 + 空态；节点浏览/详情（只读）。
- **HTML 渲染器**（本项目最大单体）：解析器（含深度熔断）+ 全部块类型渲染；用真实帖子集回归（含 104933 等历史问题帖）。
- 阅读器只读：嵌套树/折叠/深链滚动/查看器（缩放+下拉退出）/内置浏览器全规格。
**验收**：游客可完整逛站；50 个随机真实帖渲染无布局异常、无卡顿。

## M2 · 账户（1–2 周）
- 登录（帐密+2FA+OAuth）、分步注册（含兴趣节点延迟 join）、游客登录门五入口。
- 我的页 + 公开资料 + 设置骨架（偏好读写）。
**验收**：三种登录路径 + OTP 账号可登；cookie 轮换 30 分钟压力测试不掉线（07-1）。

## M3 · 读写互动（2 周）
- 赞/书签/回复/发主题/媒体上传/图片编辑/转发/打赏/关注；投票/抽奖/红包插件。
- 阅读进度上报；错误 Toast 全覆盖。
**验收**：与 web 端交叉验证每种写操作落库正确。

## M4 · 消息与实时（2 周）
- 通知/私信/群组收件箱；聊天（快照缓存 + MessageBus 实时 + 讨论串 + 已读）。
- 推送轮询（WorkManager + 分类 channel + 深链 + 水位线）。
**验收**：双端互发 1s 内可见；断网重进秒开历史；推送分类开关生效。

## M5 · 收尾（1–2 周）
- 搜索全功能、应用目录、双语文案补全、无障碍（触达尺寸/内容描述/减弱动态）、性能（启动/滚动帧率/内存）、predictive back 全链路。
**验收**：与 iOS 逐屏对照清单通过；低端机（骁龙 6 系）阅读器滚动 ≥55fps。

## 风险清单
| 风险 | 缓解 |
|------|------|
| HTML 渲染器工期膨胀 | M1 限定块类型白名单，未知块降级为纯文本+“在浏览器打开” |
| 后端字段类型踩雷 | 每个新 DTO 先抓真实响应；解码失败可观测 |
| MessageBus 行为差异 | 先用 curl 手工验证 poll 协议再写客户端 |
| 玻璃质感还原度争议 | M0 画廊页尽早对齐视觉预期 |
