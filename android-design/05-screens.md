# 05 · 逐屏规格

约定：所有列表页三态 = 骨架（首载）/内容/空态（暂无内容 vs 断网+重试）；游客可读一切，写操作入口按下节规则替换或弹注册/登录门。

## 0. 全局：游客态与登录门

- **五处头部入口统一**用 `GuestLoginButton`（汉堡同款玻璃质感的"登录"胶囊）：首页（替换"+ 发帖"）、节点浏览页（替换"+ 新建"）、节点详情工具条（替换"+"）、消息页（替换工具胶囊）、我的页（资料卡内）。
- 阅读器头像位：游客显示灰色人形图标；点击弹**底部注册/登录门**（说明文案 + 注册/登录两行，高度 ~280dp 的 sheet）。需要账号的操作（书签/转发）游客点击时：先收起当前 sheet，停 ~450ms 再弹登录门（连续弹会丢）。
- 登录入口一律进入**应用内 Auth 流程**（见 §11），不重置到冷启动欢迎页。

## 1. 首页（Feed）

- 头部（悬浮，随滚动上滑隐藏字标、玻璃按钮常驻）：汉堡 | 字标（静态，不作加载指示） | +发帖（游客=登录）。
- 列表：按 `NodeReadingModeStore` 全局模式渲染——
  - **卡片**：作者行(头像/未读点/节点名/时间/置顶章) + 标题(≤4行) + 摘要(≤3行) + 媒体（轮播，多图带页码与左右钮；视频自动播放贴片；高按媒体纵横比钳制 9:16…5:4）+ 操作行(投票/评论数/分享)。
  - **紧凑**：头像30 + 标题2行 + 节点·时间 + 回复数（与节点页同组件）。
  - **展开**：作者行 + 标题+标签 左、78dp 方缩略图右 + 操作行。
- 骨架按当前模式给对应形状（卡片3张/紧凑10行/展开5行），容器级同相位脉冲。
- 下拉刷新：自定义（阈值 72、越过即触发+触感、Lc 指示器、最短 0.6s）。
- 分页：末尾哨兵可见即 loadMore，去重 append。
- 失败空态：wifi 图标 + 友好文案 + 重试；**禁止演示数据回填**。
- 点卡片进阅读器（记录本地已读，未读点即时消失）。

## 2. 节点浏览（节点 Tab）

- 头部：返回/汉堡（视层级）| 标题 | +新建（游客=登录）。
- 分组横向卡列表 + 组内"更多"分页（`node/browse/{parent}`）；骨架=章节标题条+横向卡。
- 进入节点详情、创建节点（名称/slug 实时查重/简介/颜色/父分类，"发布后自动创建"提示）。

## 3. 节点详情

- 结构：整页同滚（banner → 节点信息卡[logo/名称/成员数/简介/加入按钮/通知级别菜单] → 排序+阅读模式栏 → 话题列表）。
- 悬浮头部：返回 | 节点身份胶囊（滚过再淡入，点击回顶）| 工具胶囊[+发帖(游客=登录)/域内搜索/更多菜单(分享、关于、通知级别)]。宽度紧张：SE 级屏只放三图标。
- 通知级别：0-4 五档（关注/跟踪/关注第一帖/常规/免打扰），菜单带说明文案，写 `category/{id}/notifications`。
- 域内搜索：进入搜索并预填 `#slug `（搜索浮层形态）。
- 阅读模式菜单驱动全局共享 store。
- 下拉刷新（同首页组件）；话题行三模式复用首页行组件。

## 4. 帖子阅读器（最重的页面）

**布局**：全屏层；悬浮头部[关闭 X | 节点胶囊(滚后淡入,回源) | 工具胶囊(搜索/回复排序/更多…/当前用户头像)]；内容 **必须 LazyColumn**（见 07 冻结教训）：作者行(#1) → 标题 → 红包横幅? → 正文块树 → 抽奖卡? → 操作栏(赞/评论数/分享/转发/打赏) → "N replies" → 回复树 → 加载更多。底部常驻回复输入条（游客显示"登录后参与讨论"）。

**正文渲染**（cooked→块树，见 04/07 解析器）：段落（文本/链接/提及/内联 emoji 图/样式 run）、标题、引用（嵌套字号-2，带作者头像行）、代码块（横向滚动+语言标）、表格、details 折叠、剧透遮罩、图片（比例占位防回流，点开查看器）、视频（贴片播放）、onebox 卡、投票/抽奖/红包插件块。长 token 打断：无断点串每 18 字插零宽空格。

**回复树**：
- 服务器嵌套树 DFS 平铺渲染，缩进上限 8 级，Reddit 式垂直导轨（Rectangles 按行高铺）。
- 行 = 头像(点开资料) + **作者名(点击=折叠)** + flair + 头衔 chip + 时间 + 展开/收起箭头；正文（**点击=折叠**，链接/图片手势优先）；红包领取标签?；操作行（打赏合计→明细 sheet、…菜单、回复、赞[自己的禁点]、打赏[自己的无]）。
- **折叠**：任意回复可折叠为单行（头像+名字+时间+▾），**其整个子树隐藏**；再点名字/整行/箭头展开。折叠集合是页内状态。
- "另外 N 个回复"行：拉 `children/{postNumber}` 增补进树。
- 深链（通知/URL 带楼层）：加载后 scrollTo 该楼层。
- 回复排序 sheet：top/new/old，重载嵌套树。
- 阅读进度：每秒给可见楼层计时（可见度≥50%），10s 批量上报 timings，退出补一次。

**更多菜单（头部 …）**：复制链接/分享/保存书签(成功 toast"已保存书签")/转发(预填撰写)/举报(内置浏览器开话题页)。书签、转发游客触发登录门。

**插件交互**：
- 投票：单选/多选(min/max)、公开投票人、结果条；`options[]` 重复键提交。
- 抽奖：票数选择/随机、参与人数门槛说明、开奖名单；创建走 JSON body。
- 红包：领取结果在回复行内以"领取了 N 能量"标签呈现（回复即自动领取）。
- 打赏：金额+留言 sheet → `reward/give`，明细 sheet 列出打赏人。

## 5. 撰写（发主题 / 回复）

- 发主题：节点选择器（搜索+最近）、标题、正文、工具条（图片[相册/编辑器]、GIF 搜索[Klipy]、投票、抽奖、红包挂件、格式化）。红包/抽奖在**发帖成功后二段创建**（插件无 markup）。
- 图片上传 `uploads.json`(composer)；上传前可进图片编辑器（裁剪/画笔/文字）。视频走裁剪器（可转 GIF，超 10s 截断提示），上传后补 `{sha1}.png` 封面。
- 回复：底部输入条展开，"回复 @xxx" 头（reply_to_post_number），成功后关闭并滚动到新楼层。失败 Toast。

## 6. 消息 Tab

- 头部：汉堡 | "收件箱" | 工具胶囊[+/已读/…]（游客=登录按钮）。分段：通知 / 私信 / 聊天（未读数徽标；Tab 徽标 = 三者之和）。
- **通知**：分类图标+统一文案（NotificationFormatter 同源）、点击深链路由；进入 Tab 时 mark-read 清徽标。空态区分登录/未登录。
- **私信**：会话行（对方头像/标题/时间/未读点），点开走阅读器；群组收件箱 chips 过滤（`private-messages-group`）。
- **聊天**：频道列表（未读、讨论串未读数）；会话页见下。

## 7. 聊天会话

- 打开：**磁盘快照立即渲染**（落底部）→ 网络最新页对账替换 → 存快照。跳指定消息时跳过快照。
- 实时：MessageBus 订阅 `/chat/{id}`，事件→静默重拉最新页（含打开中的讨论串），新消息落底。
- 发送：POST 后轻刷新（不整页重载）；发送态禁用输入。
- 讨论串：横向 rail 入口 + 串内视图（同一套气泡）；已读上报 `read?message_id=`。
- 气泡：文本+自定义 emoji 内联+图片（点开预览）；我的靠右。
- 生命周期：离开停轮询；错误退避 4s。

## 8. 搜索 Tab

- **真 Tab**：Android 用常驻顶部 SearchBar（见 06 决策）；scope 行（全部/节点/帖子/用户/应用/媒体）。
- 未输入：最近搜索（可删/历史 sheet 可清空）+ 热门词。
- 结果（一次 search.json + 应用目录本地过滤并行）：
  - 全部 = 混合分组：节点(前3) → 用户(前3) → 帖子卡；
  - 各 scope 全量列表；媒体 = 过滤带图/视频的帖子。
- 行为：用户行→公开资料；节点行→节点页；应用行→应用详情；提交记历史（≥2 字才搜，防抖）。
- 节点域内搜索是独立浮层形态（预填 `#slug `，玻璃 scope 胶囊+底部输入行）。

## 9. 我的 Tab

- banner（滚动拉伸）+ 资料卡：大头像（游客=灰人形）、姓名+头衔章、@用户名+flair+粉丝数、最近活跃/加入时间胶囊、角色 chips、徽章/常去节点入口、bio、统计行（能量/声望/主题/回复/账户年龄，未载为 --）。
- 游客：占位文案 + 统一登录按钮。
- 活动 Tabs：主题/帖子/赞/书签/能量（user_actions filter + points-history），懒加载各 Tab。
- 悬浮头部：汉堡 | 身份胶囊(滚后现,回顶) | 设置齿轮。下拉刷新强制重载。

## 10. 设置

- 分组：账户（个人资料编辑/关联账户/安全性[改密邮件/2FA 全流程/会话管理]）仅登录显示；偏好设置（界面[颜色模式/文本大小(仅同步服务器)/默认首页/阅读模式]/通知/电子邮件/跟踪/隐私/其他/网页端）；账号（通知列表入口/推送通知[仅登录]/Pro/退出登录）。
- **推送设置页**：主开关（申请系统权限；被拒时"前往系统设置"行+说明 footer）+ 分类型四开关 + "关闭的类型仍在站内显示" footer。
- 全部行组件来自设计系统 SettingsRow 族。

## 11. 登录/注册（应用内流程）

- **形态**：全屏导航流（Navigation 目的地栈），原生控件。
- **登录页**（根）：X 关闭|右上"注册"；logo；"登录"标题；协议文案；"通过 NodeLoc 网站继续"(OAuth)；"或"分隔；邮箱/用户名+密码（自动填充 hints：username/password）；**2FA 分支**：服务器要求时就地展开验证码框（autofill=sms_otp 类比 oneTimeCode）+"使用备用码"切换；忘记密码→外开重置页；底部大"继续"。
- **注册分步**（推入）：邮箱 → 用户名（`check_username` 400ms 防抖，可用绿勾"好名字！…"/占用红叉+建议名） → 密码（≥10 字符，满足变绿；autofill new-password 触发密码管理器） → 性别（男/女/其他/不愿透露 单选，仅存本地） → **兴趣节点**（随机 8 个真节点胶囊 + "换一批"，已选区可 X 删，**上限 3**，选中从待选移除） → 提交。
- 提交结果：直接激活→立即 join 所选节点并完成；需邮箱激活→激活提示页（隐藏返回，"返回登录"预填邮箱），所选节点存 DataStore，**下次经此流程登录成功时自动补 join**。
- 完成：回到原上下文（不重置导航）。
- 冷启动欢迎页保留（Get Started / 已有账号 / 游客浏览）。

## 12. 内置浏览器

- 全屏 WebView，内容满屏，镶边悬浮：
  - 顶部：X（左）| **域名胶囊**（居中；https 锁形；**背景从左到右填充 = 页面滚动进度**，accent 18%；默认与按钮同高 48，收起态缩为 28 小药丸并收窄至文本；按压有反馈）| …菜单（文字大小 A/100%/A 步进 10% 限 50–200%、系统浏览器打开、刷新、分享、复制链接）。
  - 底部胶囊：返回/前进（无历史置灰）/分享/刷新/外部打开。
  - **滚动行为**：下滑阅读→底部胶囊滑出+顶部按钮淡出只留域名药丸；上滑/到底/到顶/点药丸→恢复。阈值 6dp 防抖。
- 链接路由（全局唯一 openURL 拦截）：站内 `/t/`→阅读器（带楼层）、`/u/`→资料、`/n/|/c/`→节点、群组收件箱→消息页；其余站内+外链→内置浏览器；mailto/tel→系统。
- 顶部线性加载条（页面加载进度）。

## 13. 图片查看器

- 全屏（透明容器背景，压黑层自绘）：横滑翻页（页码 chip）、双击 2.5x/复原、捏合 1–6x、放大后拖拽平移（边界钳制）、单击切换镶边。
- **下拉退出**：竖向优先手势（|dy|>1.2|dx| 且向下）→ 图随手指下移+缩小(最低85%)、黑底渐隐(最低20%)透出下层、镶边隐藏；松手 >130dp 或高速→关闭，否则弹簧回位。**放大状态下禁用**（拖拽=平移）。
- 镶边：作者/节点信息、赞/评论转跳。视频查看器共用镶边（有传输条），暂不做下拉退出。

## 14. 应用目录

- 列表（logo/名称/简介/安装数）→ 详情（README、权限 scopes、作者）→ webview 型可全屏运行（`/apps/installs/{id}/webview`）。
